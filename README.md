## Supported versions

PHP 8.5 and 8.6. PHPUnit 10.5, 11.5, 12.5 and 13 (`phpunit/phpunit: ^10.5 || ^11.5 || ^12.5 || ^13.0`); the test suite is verified against each of these majors.
